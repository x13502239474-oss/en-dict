# 英汉词典 · English–Chinese Dictionary

纯前端英汉词典查询站，无需后端、无需联网即可查询全部词条。
界面与信息编排参照牛津高阶英汉双解词典的逻辑：**词头 → 音标 → 词性分组释义 → 词形变化 → 用法标注**。

## 快速开始

- **方式一（推荐）**：在本目录运行 `python -m http.server 8765`，浏览器打开 `http://127.0.0.1:8765`
- **方式二**：直接双击 `index.html`（数据以静态 JS 分片存放，file:// 协议同样可用）

## 功能

| 功能 | 说明 |
|---|---|
| 英汉双查 | 输入英文单词或中文释义均可查询，搜索框实时联想 |
| 词形还原 | 查 `ran` 自动定位 `run`（含不规则动词，基于词库 exchange 字段索引） |
| 拼写纠错 | 查不到时给出拼写相近词与前缀匹配建议 |
| 发音 | 联网时用英式/美式真人音频，离线时用浏览器语音合成 |
| 例句 | 联网时从开放词典接口补充英文例句 |
| 分级标注 | 柯林斯星级、牛津 3000 核心词、中考/高考/四六级/考研/雅思/托福/GRE 标签、BNC/COCA 词频 |
| 考试浏览 | 首页按考试分类浏览，按词频排序分页展示 |
| 生词本/足迹 | localStorage 持久化，支持抽屉管理与一键清空 |
| 键盘操作 | `/` 聚焦搜索，`↑↓` 选择联想，`Enter` 查询，`Esc` 关闭 |
| 主题 | 深色/浅色切换，自动记忆 |
| 离线可用 | 全部词条为本地静态分片，断网可查 |

## 数据来源与版权说明

- 释义：开源词库 **ECDICT**（MIT 协议），从原始 77 万词条中精选 49,819 条常用及考试词汇。
  牛津词典官方释义文本受版权保护，本站未收录；柯林斯星级与牛津 3000 核心词标记为公开分级信息，仅作难度参考。
- 发音/例句：联网时调用 dictionaryapi.dev 开放接口（数据来自 Wiktionary，CC 授权）。
- 在线增强失败时自动静默降级，不影响核心查询。

## 目录结构

```
en-dict/
├── index.html        页面骨架
├── styles.css        样式（深/浅主题令牌）
├── app.js            查询引擎 + 渲染 + 路由
├── build_data.py     词库裁剪脚本（源：ecdict.csv）
├── ecdict.csv        ECDICT 原始词库（63MB，可删除，重建时需要）
└── data/             生成的静态分片（共约 14MB）
    ├── core.js       4091 个高频核心词（首屏即用）
    ├── shard-a~z.js  按首字母分片，查询时懒加载
    ├── lex.js        全局词表（联想与拼写纠错）
    ├── forms.js      屈折变形 → 原形反查索引
    ├── cn.js         中文反查倒排索引
    ├── tags.js       考试标签索引
    └── meta.js       统计信息
```

## 重建数据
